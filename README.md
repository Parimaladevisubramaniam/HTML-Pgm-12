# Pseudo-class and Pseudo-element Selectors - GitHub Classroom Assignment

## Student Task

Complete `styles.css` so that the webpage demonstrates the required CSS pseudo-class and pseudo-element selectors.

### Requirements

1. Set the body font family to Arial, Helvetica, sans-serif.
2. Set the body font size to 87.5%.
3. Set the body margin to 2em.
4. Make all hyperlinks bold.
5. Use `a:link` to make unvisited links green.
6. Use `a:hover` and `a:focus` to make links fuchsia.
7. Use `main p:first-child` to make the first paragraph bold.
8. Use `main p:first-child::first-letter` to make the first letter 150%.
9. Do not remove the supplied HTML content.
10. Push the completed assignment to GitHub.

## Marks

10 automated tests × 5 marks = **50 marks**.

Run locally with:

```bash
chmod +x test.sh
./test.sh
```

The GitHub Actions workflow in `.github/workflows/autograding.yml` runs the same tests automatically after a push.
